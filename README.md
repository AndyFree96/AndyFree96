## About Me

I'm a software engineer transitioning into **automation equipment and intelligent manufacturing**, with a strong interest in building reliable software systems for machines.

My current focus sits at the intersection of:

- 🏭 Automation Equipment Development
- 👁️ Machine Vision
- 🧱 Software Architecture
- ⚙️ Industrial Control
- 🤖 AI / LLM
- 💻 Developer Tools
- 🌍 Cross-platform Applications

I enjoy going deep into systems — from hardware interfaces and industrial communication to algorithms, application architecture and developer tooling.

My long-term goal is to become a **Device Software / Automation Control Architect**, while developing deep expertise in **Machine Vision, AI, and Software Architecture**.
